# Survey Specification Generator

Generates a consolidated table specification document for SPSS survey analysis.

## Overview

This skill creates a unified `table_specification.json` that combines:
- **Indicator definitions** - How to group and aggregate variables
- **Recoding rules** - How to transform raw values into meaningful categories
- **Table specifications** - Cross-tabulation tables with dimensions, metrics, and display settings
- **Output settings** - Configuration for PowerPoint and HTML generation

The specification is generated by analyzing the filtered metadata from an SPSS (.sav) file and creating appropriate analysis tables based on the survey structure.

## When to Use

Use this skill when:
1. You have an SPSS (.sav) survey data file
2. You want to create a complete analysis specification
3. You need to define indicators, recoding rules, and tables in one pass

## Input Requirements

The skill requires:
1. **Filtered metadata** - JSON file containing variable information from the SPSS file
   - Generated by `spss_analyzer.io.MetadataTransformer.filter_variables()`
   - Contains variable names, labels, types, value labels, categories

2. **Sample data context** (optional) - First few rows of data to understand value distributions

## Output

Generates: `table_specification.json` with the following structure:

```json
{
  "metadata": {
    "version": "1.0",
    "generated_at": "2025-01-15T10:30:00Z",
    "source_file": "survey_data.sav"
  },
  "global_recodings": [
    {
      "variable": "age",
      "new_variable": "age_group",
      "type": "range_map",
      "range_mappings": [...]
    }
  ],
  "indicators": [
    {
      "id": "ind_001",
      "name": "Customer Satisfaction",
      "description": "Overall satisfaction score",
      "variables": [...],
      "aggregation": "mean",
      "recoding": {...}
    }
  ],
  "tables": [
    {
      "id": "tab_001",
      "title": "Satisfaction by Gender",
      "type": "crosstab",
      "rows": {"variable": "gender", "source": "raw"},
      "columns": {"variable": "sat_score", "source": "indicator"},
      "metrics": [...]
    }
  ],
  "output_settings": {
    "significance_threshold": 0.05,
    "include_powerpoint": true,
    "include_html_dashboard": true
  }
}
```

## Specification Guidelines

### Indicator Creation

1. **Identify related variable groups** - Look for patterns like:
   - Multiple satisfaction questions (q1, q2, q3) → Satisfaction indicator
   - Awareness questions (aware_1 to aware_10) → Brand Awareness indicator
   - Rating scales (1-5, 1-7) that need aggregation

2. **Define aggregation method**:
   - `mean` - For rating scales (e.g., satisfaction scores)
   - `sum` - For count-based metrics (e.g., awareness mentions)
   - `weighted_mean` - If using weight variables

3. **Handle recoding**:
   - Reverse code if needed (1=5, 2=4, 3=3, 4=2, 5=1)
   - Map values to meaningful scales
   - Apply value labels

### Recoding Rules

Create recodings for:
1. **Age/numeric ranges** - Group into meaningful categories
2. **Open-ended categories** - Consolidate small categories
3. **Rating scale consolidation** - Group similar responses

### Table Specifications

Generate tables for:
1. **Demographic crosstabs** - Key metrics by demographics (age, gender, region)
2. **Indicator comparisons** - Indicators by demographic segments
3. **Frequency tables** - Distribution of key categorical variables

Each table should have:
- Clear, descriptive title
- Appropriate dimensions (rows/columns)
- Relevant metrics (count, row %, column %)
- Statistical test configuration (chi-square, Cramer's V)

## Validation

The generated specification will be validated by the `survey-validate` skill for:
- Structural correctness (JSON schema)
- Variable references (all variables exist in data)
- Logical consistency (no duplicate IDs, valid thresholds)
- PSPP syntax compatibility

## Example Usage

```
Generate a table specification for this survey data.

The metadata file is at: output/filtered_metadata.json
Consider:
1. Create indicators for satisfaction questions (q1-q5)
2. Create recodings for age into groups
3. Generate crosstabs of indicators by demographics
```

## Notes

- The specification should be comprehensive but not excessive (aim for 15-25 tables)
- Focus on business-relevant comparisons
- Include both significant and non-significant tables (filtering happens later)
- Use descriptive IDs and titles for clarity

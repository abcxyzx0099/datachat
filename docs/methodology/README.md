# Agent Team Output

This directory stores materials, articles, and documents generated by the DataChat Agent Team.

## Purpose

Separates agent team outputs from the main application design documentation to maintain clarity and organization.

## Directory Structure

```
docs/agent-team/
├── README.md              # This file
├── planning/              # Phase 2 outputs (PM Agent)
│   ├── prds/             # Product Requirements Documents
│   ├── briefs/           # Product briefs
│   └── user-stories/     # User story breakdowns
├── solutioning/          # Phase 3 outputs (Architect + QA Agents)
│   ├── architecture/     # System design documents
│   ├── adrs/             # Architecture Decision Records
│   └── test-strategies/  # Test planning documents
├── implementation/       # Phase 4 outputs (DEV + QA Agents)
│   ├── summaries/        # Implementation summaries
│   ├── code-reviews/     # Code review reports
│   └── test-reports/     # Test execution reports
├── articles/             # General articles and analysis
└── research/             # Phase 1 outputs (Analyst Agent)
    ├── audits/           # Technical audit reports
    ├── briefs/           # Research briefs
    └── documentation/    # System documentation
```

## File Naming Convention

| Type | Format | Example |
|------|--------|---------|
| Research Report | `research-{topic}-{date}.md` | `research-langgraph-20250208.md` |
| Technical Audit | `audit-{component}-{date}.md` | `audit-langgraph-20250208.md` |
| Product Brief | `brief-{feature}-{date}.md` | `brief-csv-export-20250208.md` |
| PRD | `prd-{feature}-{date}.md` | `prd-csv-export-20250208.md` |
| Architecture | `arch-{component}-{date}.md` | `arch-auth-system-20250208.md` |
| ADR | `adr-{number}-{title}.md` | `adr-001-redis-caching.md` |
| Test Strategy | `test-strategy-{feature}-{date}.md` | `test-strategy-csv-export-20250208.md` |
| Code Review | `review-{pr/id}-{date}.md` | `review-142-20250208.md` |
